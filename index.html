Selected Work

Project names and details are anonymized to protect confidential business information.

Player Feedback Intelligence Pipeline

Built an end-to-end pipeline that turns raw player survey data into structured, queryable insight. Responses were extracted from survey exports and transformed through custom coding into a database, where topic modeling and sentiment analysis surfaced the themes and emotions driving player feedback. The results powered live dashboards for the game team, alongside deeper statistical write-ups for trend analysis over time.

Impact: Gave the game team a repeatable way to convert open-ended player comments into decisions, shaping design priorities and feature roadmaps with evidence instead of anecdote. Reporting that once took days became a standing, real-time view of player sentiment across the development cycle.

Topic Modeling Sentiment Analysis Power BI SQL Server Quarto Python R

Public Review Sentiment Tracker

Designed a pipeline to continuously collect player reviews from public sources, indexing them in a search-optimized database for fast retrieval across large volumes of text. Applied sentiment analysis to score each review through custom coding and stored the results for structured querying, then wrapped it all in an interactive app so stakeholders could explore sentiment trends without touching a query editor.

Impact: Gave the team a live, data-driven read on public sentiment, making it easy to separate signal from noise and see how specific discussion topics shifted overall perception. The Shiny app was adopted into regular sprint reviews and planning sessions as a shared source of truth on player reception.

Sentiment Analysis Shiny OpenSearch SQL Server Python R
