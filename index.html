Selected Work

Project names and details are anonymized to protect confidential business information.

Player Feedback Intelligence Pipeline

Built a pipeline to turn player survey responses into structured, queryable data. I extracted responses from survey exports, transformed them with custom code, and stored them in a database. Topic modeling helped identify recurring themes, while sentiment analysis measured the tone of responses. Dashboards gave the game team an ongoing view, with statistical write-ups tracking trends over time.

Impact: The pipeline gave the game team a repeatable way to use open-ended player feedback when setting design priorities and planning features. It also replaced reports that took days with a live view of player sentiment throughout development.

Topic Modeling Sentiment Analysis Power BI SQL Server Quarto Python R

Public Review Sentiment Tracker

Built a pipeline to collect player reviews from public sources and store them in a search-optimized database. I used custom code to score each review for sentiment and save the results for structured queries. An interactive app let stakeholders explore sentiment trends without writing queries.

Impact: The team used the app in sprint reviews and planning to track public sentiment and see how discussion topics changed over time.

Sentiment Analysis Shiny OpenSearch SQL Server Python R
